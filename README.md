        Sobre:
Fiz esse jogo simples para continuar praticando minha lógica de programação usando bibliotecas, funções, listas e randomização.

        Conceitos aplicados:
-Funções

-Loops

-identações e aninhamentos

          Funcionalidades: 

-O jogador escolhe entre Pedra, Papel e Tesoura para jogar contra o "PC"

-O pc escolhe aleatoriamente entre as 3 opções e joga

-O jogador pode ganhar, empatar ou perder

-Se quiser, o jogador pode iniciar uma nova rodada

           Como executar o projeto:

-Clone ou baixe esse repositório: https://github.com/Epic10ka/Pedra-Papel-e-Tesoura

-Abra a pasta do projeto

-Execute o arquivo ppt.py e divirta-se
